# إخراج التاريخ بالصور — العينة المعتمدة

يعيد GitHub إنتاج نفس عينة دنكرك التي وافق عليها المستخدم: 11.5 ثانية، 1080×1920، 30 إطارًا، صور وحركة كاميرا وطبقات وخريطة ونص عربي.

## التشغيل من GitHub

Actions → **History Photo Motion** → **Run workflow**.
بعد نجاح التشغيل، حمّل artifact باسم `history-photo-motion-approved`؛ يحتوي الفيديو وتقرير المقارنة.

العينة المعتمدة محفوظة بأصولها: صورتا الشاطئ وطاولة التخطيط والجندي الشفاف والخطوط والصوت. لا يستبدل التشغيل الصوت بصوت TTS ولا يعيد توليد الصور بصورة مختلفة.

## ماذا يحدث تلقائيًا؟

1. تثبيت نسخ أدوات الرسم المحددة وتشغيل FFmpeg.
2. تحريك الصور والطبقة الأمامية والانتقالات والخريطة وتركيب النصوص.
3. دمج مقتطف الصوت الأصلي دون تغيير السرعة أو طبقة الصوت.
4. التحقق من بصمات الأصول والصوت، ومقارنة أربع نقاط زمنية بمرجع العينة المعتمدة.
5. فحص الفيديو النهائي ورفعه للتحميل.

لا توجد خدمات مدفوعة أو مفاتيح API مطلوبة لإعادة تصدير هذه العينة. تنطبق حدود GitHub Actions والتخزين على الحساب.

## حدود مهمة

هذه نسخة تشغيل للإخراج المعتمد وليست توليد حلقات جديدة تلقائيًا. الصوت مقتطف من تسجيل المستخدم `135999.mp4`. توليد نص جديد بنفس الهوية الصوتية يحتاج إعدادات مزوّد الصوت في مشروع Manus؛ لا يُستبدل تلقائيًا بصوت آخر.

الصور مولّدة كإعادة بناء توضيحية وليست صورًا أرشيفية. الخريطة محدد موقع إقليمي؛ خطوطها ليست مسارات عسكرية موثقة. لا توجد خطوة نشر اجتماعي أو جدولة في هذا التشغيل.

## تشغيل محلي

```bash
pip install -r history_visual/requirements.txt
python history_visual/render.py
python history_visual/verify.py
```

يلزم FFmpeg وPillow بدعم libraqm. النتيجة في `history_visual/output/dunkirk-visual-v2.mp4`.
قد تختلف بايتات الترميز باختلاف نسخة FFmpeg؛ فحص المقارنة يسمح بفروق ضغط طفيفة ولا يشترط تطابق ملف MP4 بتًا ببت.

## مصادر الأصول

- الصور الثلاث: مولّدة بأداة imagegen المدمجة ثم اعتمدها المستخدم ضمن الفيديو. إعادة الرندر تستخدم الملفات نفسها، ولا تستدعي خدمة توليد صور.
- الصوت: أول 11.5 ثانية من `135999.mp4`؛ محفوظ بضغط FLAC بلا فقد. فك الضغط يطابق PCM المستخدم في العينة.
- Natural Earth 1:50m admin0 — ملكية عامة: https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_50m_admin_0_countries.geojson
- Noto Sans Arabic: الترخيص المرفق في assets/Noto-Fonts-Copyright.txt.
