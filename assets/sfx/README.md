# مؤثرات islamic-reminder-videos

حزمة مؤثرات طبيعية هادئة وغير موسيقية، مع مراعاة بقاء السرد واضحًا ومحترمًا:

- `reminder_soft_breeze.mp3`: نسمة فجر لافتتاح المقطع.
- `reminder_page_turn.mp3`: تقليب صفحة واحد.
- `reminder_nature_ambience_loop.mp3`: جو طبيعي صباحي قابل للتكرار تحت السرد.

لا يحتوي خط الإنتاج على موسيقى خلفية. الناتج الجديد هو `downloaded_clips/narration.mp3` ويحتوي على صوت السرد فقط؛ استخدم المؤثرات عند الحاجة في المونتاج دون أناشيد أو ألحان.
