# مؤثرات SFX — التاريخ الموثّق

هذه ملفات مؤثرات غير موسيقية، وتبقى منفصلة عن مقطوعات الخلفية الموجودة في `assets/music/`:

- `documentary_soft_breeze.mp3`: نسمة افتتاحية قصيرة.
- `documentary_page_turn.mp3`: تقليب صفحة.
- `documentary_nature_ambience_loop.mp3`: أجواء طبيعية هادئة، وليست مقطوعة موسيقية.

اختيار الموسيقى الخلفية يقرأ حصريًا `assets/music/`؛ لذلك لا تدخل هذه الملفات في التدوير ولا تُعامل كمسارات موسيقية. ملفات SFX محتفظ بها كأصول مستقلة ولا تُضاف في مسار المزج الموسيقي الحالي.
