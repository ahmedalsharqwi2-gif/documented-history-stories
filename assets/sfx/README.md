# مؤثرات documented-history-stories

حزمة مؤثرات طبيعية هادئة وغير موسيقية، مع مراعاة بقاء السرد واضحًا ومحترمًا:

- `documentary_soft_breeze.mp3`: نسمة فجر لافتتاح المقطع.
- `documentary_page_turn.mp3`: تقليب صفحة واحد.
- `documentary_nature_ambience_loop.mp3`: جو طبيعي صباحي قابل للتكرار تحت السرد.

يضيف مسار المونتاج المؤثرات تلقائيًا: جو الطبيعة عند `0.035`، نسمة افتتاحية عند `0.14`، وتقليب صفحة عند 48% من مدة الحلقة عند `0.14`، مع limiter نهائي `-0.45 dBFS`. ملف `narration.mp3` يظل صوت السرد النظيف للفحوص، والفيديو النهائي يستخدم النسخة الممزوجة. لا توجد موسيقى أو أناشيد.
