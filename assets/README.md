# مراجع الأصوات العربية

يحتوي `assets/voices/` على ثمانية ملفات مرجعية عربية مع ملفات النص المطابقة لها، ويختار ملف GitHub Actions ملفًا واحدًا لكل فيديو عبر إدخال `voice_profile` عند التشغيل اليدوي. التشغيل المجدول يستخدم القيمة الافتراضية `mohamed_elbed`.

الملفات في `assets/voices/voice_profiles.json` هي مصدر الحقيقة لاسم الملف والاسم الظاهر والنص المرجعي. أضف لكل صوت ملف WAV وملف TXT مطابقين، ثم أضفهما إلى الكتالوج. الأصوات الحالية: `mohamed_elbed`، `rafik_sa`، `egyptian_female`، `hossam`، `hossam_uploaded`، `marwan`، `nassim`، و`ahmed_z`.

## مواصفات المرجع

- ملف WAV أحادي القناة، PCM 16-bit، بمعدل 24 kHz.
- كلام عربي واضح لمتحدث واحد، من دون موسيقى أو صدى أو ضوضاء.
- يجب أن يطابق ملف TXT الكلمات المنطوقة في المقطع المرجعي.
- استخدم التسجيلات فقط إذا كان لديك إذن باستخدام الصوت ونشره.

توليد الصوت في هذا المشروع يستخدم محرك SILMA، ويُمرّر WAV والنص المرجعي المطابق تلقائيًا بحسب الاختيار. لا تضع أسرارًا أو مفاتيح API في الكتالوج.
