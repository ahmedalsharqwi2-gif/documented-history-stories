# موسيقى الخلفية — التاريخ الموثّق

هذه مقطوعات موسيقية أصلية مخصصة للخلفية تحت التعليق الصوتي، ومنفصلة عن مؤثرات `assets/sfx/`:

- `history_archive_reflection.mp3` — تأمل أرشيفي ووثائقي.
- `history_civilizations_motif.mp3` — لمسة وترية شرقية هادئة.
- `history_expedition_journey.mp3` — مسار رحلات واكتشاف.

يختار `scripts/music_rotation.py` ملفًا واحدًا فقط من هذا المجلد بترتيب أسماء الملفات، اعتمادًا على `MUSIC_ROTATION_INDEX` أو `GITHUB_RUN_ID` (mod عدد المسارات). وتُمزج الموسيقى تحت الراوي عبر FFmpeg مع خفض تلقائي للصوت الموسيقي عند الكلام. لا يجري فحص مجلد SFX أو اختيار أي ملف منه كخلفية موسيقية.

## إضافات موسيقية أصلية

مقطعا خلفية آليان جديدان لهذا المشروع، مؤلفان برمجيًا دون تسجيلات خارجية أو غناء. مدة كل مقطع ٣٢ ثانية، ويكرر مسار المزج الملف بحسب مدة الفيديو مع خفضه أثناء الكلام.

- `history_stone_echoes.mp3`
- `history_sailing_charts.mp3`

تدخل هذه الملفات مع المقاطع السابقة في التدوير حسب رقم تشغيل الإنتاج. المؤثرات الصوتية في `assets/sfx` لا تدخل في قائمة الموسيقى.
