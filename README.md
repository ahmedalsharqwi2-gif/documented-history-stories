# قصص التاريخ الموثّق — Documented History Stories

مستودع إنتاج قناة YouTube للقصص التاريخية الحقيقية والمثيرة والموثقة.

## الهوية الجديدة

- التاريخ الإنساني، الحضارات، الحروب، الكوارث، الرحلات، الاكتشافات، القضايا والاختفاءات الموثقة.
- الحقيقة أولًا، والإثارة ثانيًا، والإنتاج ثالثًا.
- لا تُقدَّم الأسطورة أو النظرية كحقيقة.
- الأنبياء والصحابة والمحتوى الديني خارج نطاق القناة.
- المصادر والتقارير اختيارية في التشغيل الحالي، وفق `HISTORY_SOURCE_GATE_ENABLED=false`.
- منع اختلاق الأحداث والاقتباسات يبقى في تعليمات التوليد؛ هذا الوضع لا يعني تحققًا مستقلًا من صحة الوقائع.
- المطابقة البصرية والصوتية ومنع التكرار تظل شروطًا للنشر.

## بوابات الأمان

1. فحص نطاق القناة وطول السرد والمشاهد: `scripts/source_integrity_gate.py`؛ اشتراط المصادر معطل في التشغيل الحالي.
2. استبعاد المحتوى الديني: `scripts/historical_verification_gate.py`؛ يمكن تفعيل اشتراط حزمة المصادر مجددًا بقيمة `HISTORY_SOURCE_GATE_ENABLED=true`.
3. فحص اللغة العربية والصوت والترجمة.
4. فحص الحقبة والمكان والأدوات والمشهد.
5. منع التكرار عبر `state/topic_history.json`.
6. النشر الخارجي متوقف افتراضيًا حتى تفعيل `PUBLISH_ENABLED=true` بعد مراجعة بشرية.

## التشغيل

```bash
python3 -m py_compile scripts/*.py
python3 -m unittest discover -s tests -p 'test_*.py' -q
python3 scripts/generate_script.py
```

عند تفعيل وضع المصادر الصارم فقط، تحتاج الحلقة إلى حزمة المصادر والتقارير كاملة. في الوضع الحالي يمكن أن تكون المراجع فارغة، ولا تُضاف مراجع وهمية أو علامة تحقق مستقل.

السجل القديم محفوظ في `archive/legacy-islamic/` لأغراض التدقيق فقط، ولا يدخل في بنك الموضوعات الجديد أو دورة الإنتاج.
